## ✨ What This Skill Does

Once installed, your AI agent becomes an **LLM Engineering Expert** that can:

| Capability | What You Get |
|-----------|-------------|
| 📝 **Prompt Engineering** | Write, optimize, and debug prompts. Chain-of-thought, few-shot, structured output, system prompts |
| 🤖 **AI Agents** | Design and build agents with tools, memory, planning. Single and multi-agent architectures |
| 🎯 **Fine-tuning** | Know when to fine-tune vs prompt. Data prep, LoRA, OpenAI fine-tune API, evaluation |

**Works with:** OpenAI, Anthropic Claude, Google Gemini, Meta Llama, Mistral — and any other LLM platform.

## 🚀 Installation

### Global Install (all projects)
Copy the `ai-llm-pro` folder to your Antigravity global skills directory:

```
~/.gemini/config/skills/ai-llm-pro/
```

### Project Install (single project)
Copy to your project's `.agents/skills/` folder:

```
your-project/
└── .agents/
    └── skills/
        └── ai-llm-pro/
```

### Download
```powershell
# PowerShell (Windows)
Invoke-WebRequest -Uri "https://github.com/syncshiftstudios-cloud/ai-llm-pro-skill/archive/refs/heads/main.zip" -OutFile "ai-llm-pro-skill.zip"
Expand-Archive ai-llm-pro-skill.zip
```

```bash
# Git
git clone https://github.com/syncshiftstudios-cloud/ai-llm-pro-skill.git
```

## 💡 How to Use

After installing, just ask your AI agent naturally:

```
"Help me write a better prompt for..."
"Build me an AI agent that can..."
"Should I fine-tune or use RAG for..."
"Why is my prompt giving inconsistent results?"
"Design a multi-agent pipeline for..."
```

The agent will automatically activate this skill and give you **expert-level answers**.
